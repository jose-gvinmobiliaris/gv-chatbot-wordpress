# GV Chatbot WordPress

Plugin de chatbot comercial de GV Inmobiliaria.

## Estructura

- gv-chatbot.php: archivo principal del plugin.
- assets/css/styles.css: estilos del chatbot.
- assets/js/api.js: conexión con la API Laravel.
- assets/js/app.js: lógica e interacción del chatbot.

## API

https://api.gyvinmobiliaria.com/api/chat
